# Document Format Standard

Every document submitted for this project follows the format the lecturer specified in "Document format.pptx". This file records those rules so that all four members produce consistent documents, and so that the conversion tool can enforce them automatically.

---

## 1. Page and text formatting

| Rule | Setting |
|---|---|
| Font | Times New Roman throughout |
| Body text size | 12 point |
| Line spacing | 1.5 |
| Alignment | Justified |
| Headings | Numbered, bold, larger than body text, using the word processor's Heading styles |
| Main sections | Each chapter or main section starts on a new page |
| Bullets and numbering | Uniform throughout the document |

Use bullets only for short points. When a point runs long, write it as a paragraph instead.

Headings must use the actual Heading style in Word, not manually enlarged bold text. The table of contents is generated from those styles, so a manually formatted heading will be missing from it.

---

## 2. Page numbering

| Part of document | Numbering |
|---|---|
| First page | No page number shown |
| Pages before the introduction | Roman numerals: ii, iii, iv |
| Introduction onwards | Arabic numerals restarting at 1 |

This requires section breaks in Word. The conversion tool applies simple Arabic numbering; the roman-numeral front matter is added by hand for the documents that have front matter, which in practice means the requirements document and the final report.

---

## 3. Front matter order

1. Title page
2. Declaration
3. Dedication, kept short
4. Acknowledgement, naming each person and the reason for the appreciation
5. Table of contents, generated by the word processor
6. List of tables
7. List of figures
8. Abstract

The list of tables and the list of figures come **after** the table of contents.

---

## 4. Tables and figures

| Element | Caption position | Numbering |
|---|---|---|
| Table | Above the table | Table 1, Table 2, Table 3 |
| Figure | Below the figure | By section, so the third figure in section 2 is Figure 2.3 |

Every table and figure must be referred to in the body text before it appears, for example "Table 4 shows the supplier lead time distribution". Text always comes before the graphic. Any figure taken from another source must be cited.

Keep decimal places consistent and minimal inside tables. A column of times reading 28.35 and 7.21 is easier to read than 28.35221 and 7.218812.

---

## 5. Tense and voice

This is the rule most often broken, and it differs by document.

| Document | Tense |
|---|---|
| Design document | Mostly future, since the work is not yet done. Past tense only for what has already been completed |
| Requirements document | Future when promising future work, past for work already carried out |
| Final report | Past, since it is an account of what happened |
| Abstract | Past |
| Methodology | Past tense and passive voice, third person |

**The methodology section must not use "we", "I" or "you".**

Write: "The questionnaire was distributed to six organisations."
Not: "We distributed the questionnaire to six organisations."

Write complete sentences. "The tank was filled with 5 litres of water", not "Fill tank with 5L of water".

Note that this overrides the usual preference for first-person writing. These are academic submissions, and the lecturer's requirement takes precedence.

## 6. Report structure

The final report contains these sections in this order:

1. Abstract
2. Introduction and objectives
3. Background
4. Methodology and procedure
5. Results
6. Discussion
7. Conclusion
8. Recommendations

### 6.1 Abstract

One paragraph to one page, in past tense, containing: the research problem or main objective, the methodology used, the main findings, and the conclusions. The lecturer's example is structured as Introduction, Methods, Results, Conclusion, and following that structure is the safest choice.

### 6.2 Objectives

Objectives must be brief, in logical sequence, realistic within the time and resources available, and phrased using action verbs that can actually be measured: assess, determine, compare, verify, calculate, describe.

Objectives are **static once the work begins**. They are not moving targets, so they must not be quietly rewritten later to match whatever was achieved.

### 6.3 Background

Includes the theory, any equations required, and the references. **Every equation is numbered.**

### 6.4 Methodology

Explain the data used, its source, and any adjustments made to it. Explain and justify the analytical assumptions, and be explicit about the models used. Describe problems encountered and how they were resolved, including approaches that did not work, since that helps others avoid the same mistakes. Make clear how calculations were made. Define every variable, including its unit of measurement.

### 6.5 Results

State the results in the text **before** presenting any graph, figure or table. Point out the most significant findings, indicate key trends, and highlight both expected and unexpected results. Include error analysis. Write in past tense.

A useful working order is to build the tables and figures first, then write the narrative that explains them.

### 6.6 Discussion

Explain why the observed results occurred. Offer hypotheses for anything unexpected. Compare against the literature, stating whether the work confirms or departs from previous studies. Empirical results are the beginning of the analysis, not the end of it.

### 6.7 Conclusion and recommendations

Cover what was learned, the strengths and weaknesses of the study, and how the work can be applied. Recommendations state what would be done differently.

## 7. Language

- Be straightforward and concise
- Use simple terms, not jargon
- Keep sentences to a maximum of 20 words
- Be specific, avoiding vague words such as "close", "like", "pretty" or "roughly"
- One theme per paragraph
- Spell check, then proofread repeatedly. A spell checker accepts "This technique cam also by applies to the analysis or gold bills" without complaint

---

## 8. Citations

Cite whenever quoting, paraphrasing or summarising work that is not your own. Direct quotation is discouraged, and copying is prohibited outright.

Citable sources include books, journal and newspaper articles, interviews, conference proceedings and lectures. Interviews conducted for this project are citable sources, so the interview log doubles as a reference list.

## 9. Producing the documents

Working documents live in this repository as Markdown, which is easy to review and to track in version control. The Word versions are generated from them:

Convert a single document:

```
python tools/md2docx.py "docs/Data Collection Plan.md" "docs/Data Collection Plan.docx"
```

Convert every document:

```
python tools/md2docx.py --all
```

The tool applies Times New Roman 12, 1.5 line spacing, justified text, numbered heading styles, a page break before each main section, table captions above tables with automatic numbering, and a page number field in the footer.

To give a table a caption, put a comment line directly above it in the Markdown:

```
<!-- Table: Supplier lead time distribution by printer -->
```

If a conversion is skipped, the Word file is open. Close it and run the command again.

Front matter, roman numeral page numbering for the pages before the introduction, and the generated table of contents are added in Word for the documents that need them, since those depend on section breaks the tool does not create.

## 10. Checklist before submitting any document

- [ ] Times New Roman 12, line spacing 1.5, justified
- [ ] All headings use Word Heading styles and are numbered
- [ ] Each main section starts on a new page
- [ ] Table of contents generated, not typed by hand
- [ ] List of tables and list of figures follow the table of contents
- [ ] Table captions above, figure captions below
- [ ] Every table and figure referred to in the text before it appears
- [ ] Every equation numbered
- [ ] Correct tense for this document type
- [ ] No "we", "I" or "you" in the methodology
- [ ] Sentences within 20 words, one theme per paragraph
- [ ] Page numbers present, first page unnumbered
- [ ] Group number shown on the document
- [ ] All sources cited, nothing copied
- [ ] Spell checked and proofread by a second member
